obdtui

Linux OBD-II diagnostic TUI. Read live PIDs and DTCs. Save capture sessions for other projects.

Status: Phase 0 · Issue #1 · Read-only by default · Not a full FORScan replacement

Source install.sh

What you get

  • USB ELM327 / STN serial path
  • Live Mode 01 data and DTC list
  • Capture packages: frames, signals, meta
  • Offline replay without a vehicle
  • Vehicle profiles as YAML (multi-make ready)
  • Bus tags for future HS-CAN / MS-CAN work

USB and Bluetooth

Wired USB serial and Bluetooth classic SPP use the same ELM protocol. Auto-detect prefers USB when both are present. Use --prefer to choose. 

obdtui --list-ports
obdtui --prefer usb
obdtui --bt-mac AA:BB:CC:DD:EE:FF
obdtui --port /dev/rfcomm0 --prefer bluetooth

Build from source

git clone https://github.com/theesfeld/obdtui.git
cd obdtui
cargo build --release -p obd-tui
./target/release/obdtui --replay fixtures/sample-session

Safety

Default mode is read-only. Clear DTCs only with --allow-writes.

Phase 0 does not program modules or write as-built data.
